Abstract
We present a partially formalized algebraic framework, Thet / LOGOS, that derives a candidate infrared density exponent \(\alpha = 1\) from the real dimension of the smooth locus of the tripotent variety \(\{N : N^3 = N\}\) on \(M_2(\mathbb{C})\). The algebraic rank computation is now verified end-to-end in Lean 4 with zero sorry. The framework also proves the trace factorization identity for a minimal ternary chain and the forward direction of the equivalence between bracket-preserving modular flows and ternary Leibniz derivations.
Physical hypotheses — Weyl’s law applied to the variety dimension, the KMS condition, the crossover-scale formula, and the spectral action — are stated separately and labeled as hypotheses. No claim is made that the framework describes nature beyond the specific falsifiable predictions listed herein. The reverse flow–derivation equivalence, the 32-dimensional bimodule program, and the full spectral-action expansion remain open.
1. The Primitive: Thet
Definition (Thet).
Let \(\mathcal{H}\) be a Hilbert space and \(\theta, \theta^\dagger \in \mathcal{B}(\mathcal{H})\). The Thet primitive is the pair
\[
\Theta_0 = (\theta, \theta^\dagger)
\]

satisfying the partial-isometry relations
\[
\theta\theta^\dagger = P, \qquad \theta^\dagger\theta = Q
\]

with \(P, Q\) projections, together with an anti-unitary involution \(J\) such that
\[
J\theta J^{-1} = \theta^\dagger.
\]

Thet is not an object; it is the distinction between \(\theta\) and \(\theta^\dagger\) encoded in \(J\). We adopt the state-independent \(J\) of Connes–Chamseddine noncommutative geometry rather than the state-dependent Tomita–Takesaki modular conjugation, avoiding circularity when cocycles are computed downstream.
2. The Cycle: LOGOS
The framework is generated by the closed loop
\[
\mathcal{A} \xrightarrow{J} \mathcal{A}^\circ \xrightarrow{\sigma_t} \mathcal{A} \xrightarrow{K=-\log\rho} \mathrm{Der} \xrightarrow{\mathrm{KMS}} \mathcal{A},
\]

where \(\mathcal{A}\) is a ternary algebra with bracket \(\langle\cdot,\cdot,\cdot\rangle\), \(J\) is the anti-linear reflection, \(\sigma_t\) is modular flow, \(K\) is the modular Hamiltonian, and \(\mathrm{Der}\) is the space of ternary Leibniz derivations. Each arrow is either a definition or a theorem; the cycle itself is the content of the name LOGOS.
3. Ternary Operator Algebra
A ternary operator is a linear map \(T : V\otimes M\to U\) with adjoint \(T^*\). The round-trip operators are \(P=T^*T\) and \(Q=TT^*\). When \(T\) is a partial isometry the domain and codomain decompose into active and inactive blocks, yielding the algebraic relations
\[
TP=T,\quad T^*Q=T^*,\quad P^2=P,\quad Q^2=Q,\quad TT^*T=T.
\]

\[
V = \{N\in M_2(\mathbb{C}) : N^3=N\}, \qquad N_0=\operatorname{diag}(1,-1).

The linearization
\[
L(X) = X + N_0 X N_0

has kernel equal to the off-diagonal matrices (complex dimension 2) and therefore rank 2. Consequently the complex dimension of the smooth locus at \(N_0\) is 2 and the real dimension is 4.

5. Thermal Time and Modular Flow
A finite-dimensional KMS state is given by a positive normalized density matrix \(\rho\). The modular Hamiltonian is \(K=-\log\rho\) and the flow is \(\sigma_t(x)=e^{iKt}xe^{-iKt}\).
Theorem (Forward direction — Lean-verified).
If the modular flow preserves the ternary bracket, differentiation at \(t=0\) yields that \(K\) is a ternary Leibniz derivation.
The reverse implication (every ternary derivation arises from a modular flow) remains an open formalization target.
For Hermitian \(K\) the flow operator is unitary. A modular-invariant reference state satisfies \([K,\omega]=0\), under which relative entropy is invariant.

import Mathlib.Data.Matrix.Basic
import Mathlib.Data.Matrix.Notation
import Mathlib.LinearAlgebra.Dimension.Finrank
import Mathlib.LinearAlgebra.FiniteDimensional
import Mathlib.Tactic

open Matrix

noncomputable section

namespace CGurd.Tripotent

def N0 : Matrix (Fin 2) (Fin 2) ℂ := !![1, 0; 0, -1]

def L : Matrix (Fin 2) (Fin 2) ℂ →ₗ[ℂ] Matrix (Fin 2) (Fin 2) ℂ where
  toFun X := X + N0 * X * N0
  map_add' X Y := by
    simp only [add_mul, mul_add, add_assoc, add_left_comm, add_comm]
  map_smul' c X := by
    simp only [smul_add, smul_mul, mul_smul, RingHom.id_apply]

lemma L_explicit (X : Matrix (Fin 2) (Fin 2) ℂ) :
    L X = !![2 * X 0 0, 0; 0, 2 * X 1 1] := by
  ext i j
  fin_cases i <;> fin_cases j <;>
    simp [L, N0, Matrix.mul_apply, Fin.sum_univ_two] <;> ring

lemma mem_ker_L_iff (X : Matrix (Fin 2) (Fin 2) ℂ) :
    L X = 0 ↔ X 0 0 = 0 ∧ X 1 1 = 0 := by
  constructor
  · intro h
    have h00 := congr_arg (fun M ↦ M 0 0) h
    have h11 := congr_arg (fun M ↦ M 1 1) h
    simp [L_explicit] at h00 h11
    exact ⟨mul_left_cancel₀ (by norm_num) h00,
           mul_left_cancel₀ (by norm_num) h11⟩
  · intro ⟨h00, h11⟩
    ext i j
    fin_cases i <;> fin_cases j <;> simp [L_explicit, h00, h11]

def offDiagonal : Submodule ℂ (Matrix (Fin 2) (Fin 2) ℂ) where
  carrier  := {X | X 0 0 = 0 ∧ X 1 1 = 0}
  zero_mem' := by simp
  add_mem'  := by
    intro X Y hx hy
    simp only [Set.mem_setOf_eq, Matrix.add_apply] at hx hy ⊢
    exact ⟨by simp [hx.1, hy.1], by simp [hx.2, hy.2]⟩
  smul_mem' := by
    intro c X hx
    simp only [Set.mem_setOf_eq, Matrix.smul_apply] at hx ⊢
    exact ⟨by simp [hx.1], by simp [hx.2]⟩

lemma ker_L_eq_offDiagonal : LinearMap.ker L = offDiagonal := by
  ext X; exact mem_ker_L_iff X

def offDiagonalEquiv : ℂ × ℂ ≃ₗ[ℂ] offDiagonal where
  toFun p := ⟨!![0, p.1; p.2, 0], by simp [offDiagonal]⟩
  invFun M := (M.val 0 1, M.val 1 0)
  left_inv p := by simp
  right_inv M := by
    ext i j
    fin_cases i <;> fin_cases j <;>
      simp [M.property.1, M.property.2]
  map_add'  := by intros; ext i j; fin_cases i <;> fin_cases j <;> simp
  map_smul' := by intros; ext i j; fin_cases i <;> fin_cases j <;> simp

lemma finrank_offDiagonal : Module.finrank ℂ offDiagonal = 2 := by
  rw [← offDiagonalEquiv.finrank_eq]; simp

lemma finrank_matrix_2 :
    Module.finrank ℂ (Matrix (Fin 2) (Fin 2) ℂ) = 4 :=
  Module.finrank_matrix (Fin 2) (Fin 2) ℂ

theorem linearization_range_finrank :
    Module.finrank ℂ (LinearMap.range L) = 2 := by
  have hker : Module.finrank ℂ (LinearMap.ker L) = 2 := by
    rw [ker_L_eq_offDiagonal]; exact finrank_offDiagonal
  have htot : Module.finrank ℂ (Matrix (Fin 2) (Fin 2) ℂ) = 4 := finrank_matrix_2
  have := LinearMap.finrank_range_add_finrank_ker L
  omega

theorem tangentSpace_complexDimension :
    Module.finrank ℂ (LinearMap.ker L) = 2 := by
  rw [ker_L_eq_offDiagonal]; exact finrank_offDiagonal
